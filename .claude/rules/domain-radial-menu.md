# Radial Menu

Files in `Core/RadialMenu/`, in load order:

- `Data` — preset wheels (`CM.RadialPresetList`: Interface, Emotes, Misc; first-run seed, and `CM.RadialCreateWheel(at, presetKey)` adds one later, no key = blank), `CM.RadialLayout` constants and the per-character wheel store (`char.radialMenu.wheels`, each `{name?, count, slots[1..8] = {kind = spell|item|macro|action, id}}`). Every mutation (`CM.RadialCreateWheel`/`SetSlot`/`AddSlice`/`RemoveSlice`...) ends in `CM.RadialRefresh`. No settings table.
- `Actions` — `CM.RadialActions`: UI shortcuts (map, bags, character...). Each is a plain `Button` `CombatModeRadialAct_<id>` running Blizzard functions; slices click it with `/click`. Function / micro-button names are checked against the live client; unverified ones fail soft. Icons: micromenu TGAs (`Assets/radial/radial_icon_*.tga`), Interaction HUD cursor icons for emotes, `CM.Constants.Logo` for the options action, and the sentinel `"portrait"` (player 2D portrait) painted via `CM.RadialSetIcon` (Data) wherever an entry icon is drawn.
- `Secure` — `CombatModeRadialWheel` (SecureHandlerBaseTemplate), key button, page button and 8 slice `SecureActionButtonTemplate` children. The wheel content is copied into attributes out of combat (`rn<k>`, `rt<k>_<i>`, `rv<k>_<i>`...); the key press shows the wheel, aiming is `owner:GetMousePosition()` (fractions 0..1) against per-slice direction attributes, release clicks the aimed slice and hides. While open, the wheel owner takes MOUSEWHEELUP/DOWN (page) and ESCAPE (cancel) as override bindings. Edits made in combat are queued (`CM.TryApplyBindingChange`) and flushed on `PLAYER_REGEN_ENABLED`.
- `View` — insecure art/labels/cooldowns as a child of the wheel (`radial_{bg,sel,off}_N.tga`) plus wheel page dots under the centre text (`radial_pip_{off,active,glow,fill}.tga`, Evoker essence art on one shared canvas, untinted; one per wheel, current one active; max 5 wheels = `LAYOUT.MAX_WHEELS`, dots shrink to fit one row of `PIP_ROW_WIDTH`; each wheel has its own highlight tint, `LAYOUT.WHEEL_COLORS`). Repaints only while open.
- `RadialMenu` — façade: init, hooks wheel OnShow/OnHide, `RADIAL_MENU_EVENTS` (cooldowns, `SPELLS_CHANGED` re-store).

Mouse Look handoff: `CM.IsRadialMenuOpen` feeds `CM.ShouldFreeLookBeOff`; hiding the wheel re-locks through `CM.ReconcileFreeLook`.

Forever (interface 16xxx) cannot compile secure snippets: `CM.IsRadialMenuSecureAvailable` is false, the tab is watermarked. Cooldown values are secret on Mainline: pass them straight to the Cooldown widget inside `pcall`, never compare. UI: `UI/Options/Tabs/TabRadialMenu.lua` only (no separate window): a custom row drawing the wheel with 8 pooled slice buttons (click = searchable dropdown of UI actions / emotes / slice, drop spell/item/toy/mount/macro = assign, right-click = remove, never the last, left-drag a slice around the wheel = it trades places with its neighbours, wrapping at the ends, committed via `CM.RadialReorderSlots`), the wheel title on top (click to rename, `CM.RadialRenameWheel`) with page arrows either side, an accent "Add Slice" slice drawn on the wheel in the next free position, and a centre disc split in two halves (red "-" removes the wheel, green "+" opens a menu of the presets + Blank Wheel). A wheel stores an optional `name` (default "Wheel k") and `count` slices (editor positions); empty ones are skipped by the live wheel. There is no enable toggle (unbound key = off) and no scale / dead-zone option (`LAYOUT.DEAD_ZONE`).
